#  SunCart - Summer Essentials Store

##  Live URL
https://sun-cart-phi.vercel.app

##  Project Purpose

SunCart is a modern summer eCommerce platform where users can explore and purchase seasonal products such as sunglasses, summer outfits, skincare products, beach accessories, and more. Users can browse products, view detailed information, and access protected product pages after authentication.

##  Key Features

- Responsive design for Mobile, Tablet, and Desktop
- Better Auth Authentication System
- Email & Password Login/Register
- Google Social Login
- Protected Product Details Route
- Redirect back after successful login
- Dynamic Product Details Page
- Dynamic Metadata for SEO
- Lottie Animation Hero Section
- Summer Care Tips Section
- Top Brands Section
- User Profile Page
- Loading States & Toast Notifications

##  Technologies Used

- Next.js 16
- React
- Tailwind CSS
- HeroUI
- Better Auth
- MongoDB
- React Icons
- React Toastify
- Lottie React
